# Sasha Miriti — Portfolio

My personal portfolio website, built as part of IS Project II to demonstrate a professional Git/GitHub workflow.

## Live Site

[https://is-project-2026.github.io/portfolio-166394/](https://is-project-2026.github.io/portfolio-166394/)

## About

This site showcases who I am, my projects, and how to get in touch. It was built to practice Agile planning (milestones, issues, project boards), branch-based development, Conventional Commits, pull requests, merge conflict resolution, and deployment via GitHub Pages.

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)
- GitHub Pages (deployment)
- Git & GitHub (version control, Agile project management)

## Development Workflow

- All development done on feature branches (`feat/`, `fix/`, `chore/`, `refactor/` prefixes)
- Changes merged via Pull Requests, following Conventional Commits
- Branch protection enabled on `main`
- Project tracked via GitHub Milestones, Issues, and a Kanban board
